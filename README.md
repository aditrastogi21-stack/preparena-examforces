# ⚡ PrepArena — ExamForces

> A Codeforces-style rated contest platform for JEE & NEET. Compete in Div 1–4 contests with per-question timers, anti-cheat tab detection, and post-contest analysis. Study with Feynman explanations, PYQ revision sheets & an AI doubt solver. One HTML file. No install.

## 🚀 Live Demo

**[▶ Open PrepArena](https://aditrastogi21-stack.github.io/preparena-examforces)**

---

## ✨ Features

| Feature | Description |
|---|---|
| 🏆 **Rated Contests** | Div 1–4 divisions, Codeforces-style rating from base 1000 |
| ⏱️ **Per-Question Timers** | Each question has its own timer that pauses when you switch |
| 🛡️ **Anti-Cheat** | Tab switching detected — each violation deducts 50 rating |
| 📊 **Post-Contest Analysis** | Weak topic detection, time analysis, personalised next steps |
| 📖 **Quick Revision** | Key formulas, derivations + JEE PYQs with locked answer keys |
| 🧠 **Knowledge Hub** | Feynman-style explanations (Simple → Advanced) + adaptive quiz |
| 🤖 **AI Doubt Solver** | Claude-powered step-by-step solver, accepts text or screenshots |
| 💡 **Daily Questions** | Physics, Chemistry & Math MCQ every day |
| 🏅 **Leaderboard** | Live rating leaderboard updated after every contest |

## 🏁 How to Run

### Option 1 — Just open the file
```bash
git clone https://github.com/aditrastogi21-stack/preparena-examforces.git
cd preparena-examforces
open index.html
```
That's it. No `npm install`. No server. No dependencies.

### Option 2 — GitHub Pages (live website)
1. Go to repo **Settings → Pages**
2. Set source to `main` branch, `/ (root)`
3. Your app is live at `https://aditrastogi21-stack.github.io/preparena-examforces`

## 🎯 Contest System

- Everyone starts at **rating 1000**
- **Div 4 & Div 3** — Open to all
- **Div 2** — Rating ≥ 1100
- **Div 1** — Rating ≥ 1200
- **Hard + Fast = Maximum rating gain** (time bonus decays per second spent)
- **Tab switch = −50 rating** per violation
